# 📝 Student Activity to Observation
### 학생활동 → 교사관찰기록 변환 플러그인

> **"선생님, 관찰기록 작성에 몇 시간씩 쓰고 계신가요?"**
>
> 이제 AI가 도와드립니다. 학생 활동 내용만 입력하면, 자연스러운 교사관찰기록이 **몇 초 만에** 완성됩니다.

---

## ✨ 이 플러그인이 특별한 이유

### 🎯 문제: 관찰기록 작성의 어려움

선생님들이 겪는 공통적인 고민:
- "글자 수 맞추느라 시간이 너무 오래 걸려요"
- "비슷한 내용을 다르게 표현하기 어려워요"
- "NEIS 기준 바이트 수 계산이 복잡해요"

### 💡 해결: AI가 대신 해드립니다

| 기존 방식 | 이 플러그인 사용 |
|----------|----------------|
| 학생 30명 × 30분 = **15시간** | 학생 30명 × 30초 = **15분** |
| 글자 수 수동 계산 | **자동 계산 + 실시간 표시** |
| 문체 일일이 수정 | **AI가 문체 자동 교정** |

---

## 🚀 v2.2.0 신기능: AI 보조 수정

### 📖 쉽게 이해하기

**비유로 설명하면:**
> 마치 **숙련된 동료 교사**가 옆에서 "이 부분은 이렇게 고치면 어때요?"라고 조언해주는 것과 같습니다.
>
> AI가 제안하면, 선생님이 **미리보기로 확인**하고 **마음에 들면 적용**하면 됩니다.

### 🎮 사용법: 3단계로 끝

```
1️⃣ 수정 버튼 클릭 → 수정 모달 열림
2️⃣ AI 버튼 클릭 → AI가 수정안 제시
3️⃣ 미리보기 확인 → 마음에 들면 "적용" 클릭
```

### 🔧 AI 보조 기능 상세

#### 📏 글자수 조절 (한 번의 클릭으로!)

| 버튼 | 기능 | 언제 사용하나요? |
|-----|------|----------------|
| 📈 **늘리기** | 내용을 약 50자 더 풍부하게 | "글자 수가 좀 부족할 때" |
| 📉 **줄이기** | 핵심만 남기고 약 50자 압축 | "글자 수가 너무 많을 때" |
| 🎯 **목표 맞추기** | 설정한 목표 글자수에 정확히 맞춤 | "딱 맞게 조절하고 싶을 때" |

#### ✨ 빠른 개선 (문장의 품격을 높이세요)

| 버튼 | 기능 | 예시 |
|-----|------|-----|
| ✨ **다듬기** | 어색한 문장을 자연스럽게 | "열심히 했음" → "성실한 태도로 과제에 임함" |
| 🔍 **구체화** | 추상적 표현을 구체적으로 | "잘함" → "논리적 사고력을 발휘하여 문제를 해결함" |
| 📝 **문체 교정** | 교사관찰기록 문체로 변환 | "발표를 잘했다" → "발표 시 명확한 전달력을 보임" |

#### 👀 미리보기 기능

AI가 수정안을 제시하면 **바로 적용되지 않습니다**.

```
┌─────────────────────────────────────┐
│  📋 AI 수정 제안 (150자 → 180자, +30자)  │
├─────────────────────────────────────┤
│  [수정안] [원본] [비교]              │  ← 탭으로 전환 가능
├─────────────────────────────────────┤
│                                     │
│  수정된 내용이 여기에 표시됩니다...    │
│                                     │
├─────────────────────────────────────┤
│      [✅ 적용]     [❌ 취소]         │  ← 선택권은 선생님께!
└─────────────────────────────────────┘
```

**비교 탭**에서는 원본과 수정안의 차이점을 한눈에 확인할 수 있습니다.

## 📋 기본 기능

### 🔄 일괄 변환: 30명을 한 번에

1. 구글 스프레드시트에서 **학번, 이름, 활동내용** 복사
2. 플러그인에 붙여넣기
3. **"변환 시작"** 클릭
4. 완성! 결과를 다시 스프레드시트에 붙여넣기

### 📊 NEIS 기준 자동 계산

| 문자 | 글자 수 | 바이트 수 |
|-----|--------|----------|
| 한글/한자 | 1 | 3 |
| 영문/숫자 | 1 | 1 |
| 공백/특수문자 | 1 | 1 |

**실시간으로 계산되어 화면에 표시됩니다!**

### ✏️ 개별 수정 기능

변환 결과가 마음에 안 드시나요? 각 학생의 기록을 **개별적으로 수정**할 수 있습니다.

- 🖊️ 직접 타이핑으로 수정
- 🔍 맞춤법 검사 (다음 API)
- 🤖 **AI 보조 수정** (NEW!)
- 📊 실시간 글자수/바이트수 표시

## 🛠️ 설치 방법

### 방법 1: 수동 설치 (권장)

```
1. 릴리즈 페이지에서 다운로드
   - main.js
   - manifest.json
   - styles.css

2. 파일 복사 위치
   📁 [Vault]/.obsidian/plugins/student-activity-to-observation/

3. 옵시디언 재시작 후 플러그인 활성화
```

### 방법 2: BRAT 플러그인 사용

```
1. BRAT 플러그인 설치
2. "Add Beta Plugin" 선택
3. 입력: bluelion79/obsidian-student-activity-to-observation
```

## ⚙️ 초기 설정

### API 키 설정 (필수)

```
설정 → 커뮤니티 플러그인 → Student Activity to Observation

1. AI 제공자 선택 (OpenAI, Claude, Gemini, Grok 중 택1)
2. API 키 입력
3. 모델 선택 (선택사항)
4. 기본 목표 글자 수 설정 (선택사항)
```

## 📝 사용 예시

### 입력 (구글 스프레드시트에서 복사)

```
10101	김철수	프로젝트에서 리더 역할을 맡아 팀원들을 이끌었음
10102	이영희	토론에서 적극적으로 참여하여 의견을 제시함
```

### 출력 (AI 변환 결과)

```
10101	김철수	프로젝트 활동에서 리더십을 발휘하여 팀원들의 역할을
                조율하고 협력적인 분위기를 조성하는 데 기여함.
                책임감 있는 태도로 과제 완수에 앞장섬.

10102	이영희	토론 수업에서 적극적인 참여 자세를 보이며
                다양한 관점에서 의견을 개진함.
                타인의 의견을 경청하고 자신의 생각을 논리적으로
                표현하는 소통 역량이 돋보임.
```

## 🤔 자주 묻는 질문

<details>
<summary><b>Q: 변환된 결과가 마음에 안 들어요</b></summary>

**A:** 두 가지 방법이 있습니다:
1. **개별 수정**: 해당 학생의 "수정" 버튼을 클릭하여 직접 수정
2. **AI 재수정**: 수정 모달에서 AI 보조 버튼을 활용하여 자동 개선

</details>

<details>
<summary><b>Q: 글자 수가 목표와 다르게 나와요</b></summary>

**A:** AI는 때때로 정확한 글자 수를 맞추지 못할 수 있습니다.
이럴 때 **"🎯 목표 맞추기"** 버튼을 사용하세요. 설정한 목표 글자수(±15%)에 맞춰 자동 조절됩니다.

</details>

<details>
<summary><b>Q: 여러 AI 중 어떤 것이 좋나요?</b></summary>

**A:**
- **가성비**: GPT-4o Mini, Gemini 2.5 Flash
- **품질**: Claude Sonnet 4.5, GPT-4o
- **최고 품질**: Claude Opus 4.1, GPT-5
- **속도**: Claude Haiku 4.5, Grok 4.1 Fast

이미 다른 용도로 API를 사용 중이시라면, 같은 제공자를 선택하세요.

</details>

<details>
<summary><b>Q: API 사용료가 많이 나올까요?</b></summary>

**A:** 교사관찰기록은 짧은 텍스트이므로 비용이 매우 적습니다.
- 학생 30명 변환: 약 $0.01 ~ $0.10 (모델에 따라 다름)
- AI 보조 수정 1회: 약 $0.001 ~ $0.01

</details>
